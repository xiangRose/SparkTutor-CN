# SparkTutor-CN · Web

在浏览器中学习 PySpark：阅读中文讲解、动手编程、运行课程测试，再根据学习证据获得诊断、推荐和 AI 调试帮助。

本仓库默认分支 `master` 提供正式网页版。原 VS Code 扩展保存在 [vscode-legacy 分支](https://github.com/xiangRose/SparkTutor-CN/tree/vscode-legacy)，供历史版本查阅；使用当前版本无需安装 VS Code。

账号版已接通**每次作业独立容器执行**：登录后编写、运行和提交代码，由服务端为当前账号和题目创建受限容器，执行课程保留的原始断言，并把结果写入本人学习记录。管理员需先准备 Docker Linux 执行服务和课程镜像；服务未就绪、资源繁忙、超时或取消时明确显示未完成，不会以语法检查代替课程通过。

Windows 的普通 `启动网站.cmd` 会读取本机运行配置；已配置 WSL 时直接启动账号隔离实操站，继续使用原 `.sparktutor-web/` 中的账号、进度和代码。没有本机配置的新电脑仍可使用原 Windows 入口阅读课程和检查语法，真实账号实操按下面的 Linux/WSL2 步骤准备。

## 项目特色

- **循序渐进的中文课程**：两套课程共 19 课，教材 1.2.0，包含 27 道可执行编程练习和三档阅读难度。
- **浏览器学习工作区**：离线 CodeMirror 编辑器提供 Python 高亮、基础补全、搜索替换和错误行提示；代码逐题保存，支持刷新恢复、参考答案对比及实时运行输出。
- **国风界面与学习桌宠**：支持浅色、深色与窄屏布局；设置和账号管理集中在侧栏底部头像菜单。桌宠可拖动、调整大小、提问和查看最近活动，并自动避让运行、提交与导师发送区域。
- **课程测试与 AI 分工明确**：综合练习通过真实 Spark 执行课程原始断言；运行和这些测试不需要模型密钥。导师问答、调试教练及部分开放式短题评审可配置 AI。
- **可追溯的学习诊断**：从提交、调试、求助和迁移记录形成四维画像，展示样本依据、知识点证据、练习推荐、历史趋势与前后复盘。
- **分层调试帮助**：8 道练习覆盖聚合、Schema、窗口和 Join 四个主题，AI 选择错误假设和证据，系统核验后展示课程配置中的中文提示，保留分级解锁及答案影响记录。
- **学习诊断示例与环境检查**：设置页中的预设案例不计入我的学习记录，另提供环境检查和课程重置。
- **每日学习签到**：首页可主动签到，按北京时间每天记录一次，展示连续天数、累计天数和可翻月的签到日历。记录按账号保存在自己的学习数据库；签到不产生课程通过或画像评分证据，重置课程进度时保留签到记录。

## 新电脑首次安装与启动

源码仓库包含网页、教学引擎、课程、测试和已构建的编辑器资源，**不附带运行环境**。新电脑推荐在 Linux / WSL2 中部署网站和 Docker 账号隔离执行服务；安装、构建依赖时需要联网，日常打开编辑器无需 Node.js 或 CDN。项目 Python 最低版本为 3.10，推荐 3.12。

管理员只需在部署主机准备 Python、Git 和 Docker Linux 引擎，构建镜像时会安装 Java 17 与 PySpark 4.1.1。学生访问已部署的网站只需浏览器，**无需在自己的电脑另外安装 Spark、Java 或 Python**。

### Linux / WSL2（推荐：账号真实实操）

在 Linux 或 WSL2 内准备 Python 3.10+（推荐 3.12）、Git、Python venv 和可用的 Docker Linux 引擎，再在该系统的终端中运行。账号容器自带 Java 与 PySpark；网站主进程不需要另外安装宿主 Spark：

```bash
git clone https://github.com/xiangRose/SparkTutor-CN.git
cd SparkTutor-CN
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
docker build --network host -t sparktutor-executor:4.1.1 containers/executor
python -m sparktutor web --isolated-execution --host 127.0.0.1 --port 8888
```

DockerHub 不可达时，可从 Docker 官方发布到 AWS ECR 的镜像构建：在构建命令增加 `--build-arg PYTHON_BASE=public.ecr.aws/docker/library/python:3.12-slim-bookworm`。`PYSPARK_PACKAGE` 还支持带 `#sha256=...` 的公开 wheel URL，便于复用校验过的依赖缓存；普通构建默认从 PyPI 安装。构建阶段需要联网，学生作业固定无网络。

Windows 虚拟环境不能直接用于 WSL。在 Windows 中运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-web.ps1 -Runtime WSL` 可使用项目的 Linux `.venv/bin/python`、标准 `/var/run/docker.sock` 和已有数据目录。自定义环境可在本机 `.sparktutor-web/runtime.json` 保存 `runtime: "wsl"`、`wslDistribution`、`wslPythonPath`、`wslProjectPath`、`wslDockerHost`、`wslDockerExecutable`、可选的 `wslDockerService` 以及 `executorImage`；此文件不随源码分发。保存后普通 `启动网站.cmd` 自动使用该账号实操配置。Docker 服务或镜像缺失时启动器会报错，不会悄悄回到语法检查站。

### 原生 Windows 兼容入口（阅读与语法检查）

暂不准备 Docker 时，可先安装 Python 3.12 与 Git，使用兼容入口阅读课程、做选择题和检查 Python 语法，不需要安装 Java 或 PySpark：

```powershell
git clone https://github.com/xiangRose/SparkTutor-CN.git
cd SparkTutor-CN
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-web.ps1 -Runtime Windows -PythonPath .\.venv\Scripts\python.exe -ListenAddress 127.0.0.1
```

如果没有 `py` 命令，可用已安装的 Python 3.12 对应的 `python` 命令创建虚拟环境。首次安装完成后，可双击 `启动网站.cmd` 启动；没有本机 WSL 配置时优先使用 Windows `.venv`。此兼容入口不能通过必须真实执行的编程题，`Syntax OK` 不代表 Spark 或课程测试已运行。真实账号实操按上面的 Linux / WSL2 方案准备；可信单人宿主模式另见下方说明。运行窗口需要保持打开，停止服务可按 Ctrl+C。

### 打开与验证

浏览器打开 **[http://localhost:8888](http://localhost:8888)** 并登录。点击侧栏底部头像，选择“设置”，可检查隔离执行服务与镜像是否就绪；账号真实模式显示 `isolated`，就绪后再运行并提交一题。账号的执行位置由管理员配置，学习者不能切换为共享宿主 Python。设置修改需要点击“保存设置”，也不会替换正在运行的网站后端。

运行代码后应查看实际模式及退出结果；`[dry-run] Syntax OK` 只说明语法通过，代码和课程测试均未执行。真实运行和综合题判题需要完成 Spark 配置，不能用 AI 回复或语法检查代替。

若只想阅读课程、做选择题或体验合成诊断演示，可将安装命令改为 `python -m pip install -e .`，并以 `python -m sparktutor --dry-run web --host 127.0.0.1 --port 8888` 启动。该方式不能通过必须真实执行的编程题。

### 局域网演示与独立试用

启动参数默认监听 `0.0.0.0:8888`；上述首次启动示例使用 `127.0.0.1`，只允许本机访问。完成 Docker 服务和镜像准备后，局域网账号实操可用 `python -m sparktutor web --isolated-execution --host 0.0.0.0 --port 8888`；Windows 的 WSL 入口可在已保存隔离执行配置后省略 `-ListenAddress 127.0.0.1`。同一网络设备访问 `http://运行网站的电脑IPv4地址:8888`，只需浏览器，Spark 在服务端容器执行。未启用隔离服务的兼容入口仍只检查语法。

Windows 如需放行局域网访问，可在管理员 PowerShell 中运行 `.\enable-lan.ps1`；默认针对 WLAN 网卡同一子网开放 TCP 8888，有线网络可加 `-InterfaceAlias '以太网'`。端口已占用时先停止旧实例，或通过 `-Port 8889` / `--port 8889` 使用其他端口。

网页现在提供登录与注册。每个账号的进度、历史、代码草稿、练习文件和模型配置分别保存在数据目录的 `users/<用户ID>/` 下，重新登录后继续使用。浏览器草稿按用户区分，退出登录时清除本机副本，服务端记录保留。

首次启动会创建 `admin` 管理员；初始密码只写入本机数据目录下的 `accounts/initial-admin.json`，不会写入源码。管理员首次登录必须修改密码，之后可从侧栏底部头像菜单进入“管理后台”，创建学习者或管理员、停用账号、重置密码。停用、修改密码和管理员重置密码会撤销旧登录；重置后需先修改临时密码。

启用 `--isolated-execution` 的账号网页为每个作业创建独立容器，只读挂载该次作业文件，不挂载账号数据库、其他练习或模型密钥。默认全站同时 2 个作业、每账号 1 个；每个作业限制 CPU、内存、进程数、时长和输出量。未启用此服务的兼容入口仍只检查语法。浏览器不再提供数据库导出及全量清除接口；原有根目录中的单人学习记录不会自动并入新账号。

### 已有环境与本机配置

已有 Windows Python 时，可通过 `-Runtime Windows -PythonPath '你的环境\Scripts\python.exe'` 明确保留原入口；显式解释器优先于自动运行配置。启动器也兼容原 `runtime.json` 的 `pythonPath` 字段。该文件使用当前电脑的路径，不随源码分发。Windows 的 DPAPI 加密模型密钥无法直接在 Linux 解密；切换后账号、进度、代码与非敏感模型参数保留，密钥需在相应账号中重新填写，不读取或迁移其他账号的密钥。

原 `--trusted-local` / `启动本机实操.cmd` 作为可选的可信单人入口保留，只监听回环地址，使用独立 `.sparktutor-trusted-local/` 数据目录；它不替代登录账号的隔离执行。新电脑需要宿主 Spark 时可单独安装 `.[spark]`。

环境或后端代码更新后，应停止旧服务、重新启动并刷新浏览器；网页设置无法替换正在运行的 Python/Java 环境。

## 学习内容

课程以 **Apache Spark / PySpark 4.1.1** 为验证基线，教材版本 **1.2.0**，共 19 课、27 道可执行编程练习。面向会基础 Python、第一次系统学习 Spark 的中文学习者；核心 SQL、装饰器、拓扑排序和机器学习术语会在对应课中铺垫。

- **Learning Spark（11 课）**：Spark 架构与入门、DataFrame/Schema、数据源与文件格式、复杂类型与高阶函数、SQL/Catalyst、性能优化、Join 策略、Structured Streaming、数据湖与湖仓、MLlib，以及调试与迁移诊断练习。
- **Spark 4.1 教学管道（8 课）**：SparkSession、数据转换、数据读写、教学用 Pipeline 框架、Bronze 原始层、Silver 清洗层、Gold 聚合层、完整管道。

第二套课程通过自制装饰器和拓扑排序讲解编排原理，使用临时视图连接各层，**不是官方 Spark Declarative Pipelines API 的完整教程，也不等同于生产级调度系统**。官方 SDP 使用 `pyspark.pipelines` 和 `spark-pipelines`，见 [官方指南](https://spark.apache.org/docs/4.1.1/declarative-pipelines-programming-guide.html)。

流处理综合练习使用批处理 DataFrame 模拟核心变换；湖仓练习用版本化 Parquet 目录模拟历史查询。它们需要真实 Spark，但不需要 Kafka、Delta 或 Iceberg 服务，不能据此验证真实流处理容错或湖仓事务能力。

### 建议学习路线

课程采用“业务问题 → 小样例与预期结果 → 单项练习 → 综合应用 → 复盘”的组织方式，参考 [DataCamp PySpark 课程的渐进安排](https://www.datacamp.com/courses/introduction-to-pyspark)和[分层练习设计说明](https://instructor-support.datacamp.com/en/articles/2316393-exercise-sections)，讲解、样例和题目根据本项目重新编写。

1. **先入门：Learning Spark 第 1–3 课。** 第一课分成认识工具、逐项操作、CSV 综合应用三段。先用四行数据区分行数与数量，分别完成“只筛选”和“只分组求和”的可执行小练习，再组合排序和 CSV 读取。第二、三课补齐 Schema、布尔列、数组列、文件读写与临时视图。
2. **再分析：第 4–7 课。** 数组操作前区分行筛选和数组筛选；先独立完成含并列值的窗口排名，再组合数组转换。SQL 从 SELECT/WHERE 开始，以小表练习筛选、分组与聚合，再进入综合分析；Join 先确定保留哪些行，再讨论执行策略。调优强调相同结果与测量条件，不把小样例耗时当作性能结论。
3. **巩固与拓展：第 11 课及第 8–10 课。** 第 11 课对应的调试与迁移任务在完成来源题后即可练习，不必等学完流处理和机器学习。流处理、湖仓和机器学习是后续主题；开始前会说明模拟范围、先修知识和测试边界。
4. **组合项目：教学管道 8 课。** 先完成基础课程前三课或具备等效技能，先独立完成函数注册和依赖排序两个小练习，再组合成框架，逐层检查 Bronze → Silver → Gold 的输入输出，最后完成本地教学管道。

每课开头说明先修知识、可观察的学习目标与路线；综合题前提供小样例或检查点。三档难度共享综合题必需的知识与核心练习，专属内容提供类比或拓展，不自动按画像调整难度。预计时长包含阅读、编码和调试，尚未用真人试学校准，可分次完成。

分步题使用独立起始代码和课程断言，不能用上一步的变量代替题目输入。函数注册和依赖排序练习先验证普通 Python 行为，其余分步题使用真实 Spark 小表。进入第一道实操前，须在服务端准备可执行的 Spark 环境。仅语法检查不能代替课程测试，也不会放行编程题。

本轮保留原课节顺序和已有步骤标识，兼容已有题目引用及按步骤标识保存的进度；已完成课节不会自动重置。新学习者按更新后的顺序进入分步题；已有学习者重新打开课节仍会恢复旧位置，可用“上一步”回看新增练习，或在备份代码后使用“重置当前课节”重新开始。

## 使用与判题

1. 从“学习工作台”选择开始或继续学习，也可从课程目录选择课节和难度。
2. 阅读题目，在网页编辑器修改当前题目的独立起始代码；代码会保存到服务端。切题前会提交待保存修改，冲突时保留本地恢复副本并要求重新加载。
3. 点击“运行代码”查看实时输出或错误；dry-run 仅检查 Python 语法。
4. 点击“提交判题”。选择题按内容判断；短代码题进行本地检查，必要时使用模型评审；综合题使用课程原始测试，学生改动的测试区不能代替它。
5. 根据反馈修改，通过后进入下一步。阅读步骤可直接继续；参考答案可与当前作答并排比较，查看答案会记入学习记录。
6. 需要重新开始本课时使用“重置当前课节”；它清除该课进度和受管代码，保留学习历史、其他课节和旧版辅助稿。

真实执行成功且原始课程测试完成后才通过，无需 AI 密钥。课程断言覆盖题目声明的检查项，不是完整正确性证明。账号版在受限容器中执行；`trusted-local` 及其他宿主执行入口只适用于可信个人练习。

`[dry-run] Syntax OK` 表示只解析了 Python 语法，代码并未执行；变量未定义、参数不符和结果错误都可能通过语法检查。账号实操先确认隔离执行服务和课程镜像已就绪；宿主可信模式才需要选择本机或自动探测，并准备相应 Python、Java 与 PySpark。配置模型不能替代执行环境。

第一课创建 SparkSession 的短题使用本地结构检查，检查导入、`spark` 赋值、应用名 `MnMCount` 和 `local[*]`，不需要模型，支持常见的等价链式写法。本题结构检查通过不代表 Spark 已实际运行。其他没有充分本地规则的开放式短题仍可能需要 AI 辅助评审；模型未配置或连接失败时显示“尚未完成判题”，不据此认定代码有误。

选择题稳定洗牌，返回同一题保持顺序。课程提示用于当前题；导师问答可讨论概念与代码；调试教练支持聚合、Schema、窗口和 Join 四个主题的 8 道题，提供分层提示及可追溯依据，不能改分或放行。

快捷键：`Ctrl+Shift+R` 运行、`Ctrl+Shift+S` 提交、`Ctrl+Shift+N` 下一步、`Ctrl+Shift+B` 上一步、`Ctrl+Shift+H` 提示；编辑器支持搜索替换。

### 桌宠提问与未发送问题

## 学习画像、诊断与推荐（Issue #5）

打开“学习画像”，即可从本地行为记录得到四维画像、中文诊断和推荐练习：

- **Knowledge**：每道题最近一次有效评估的通过率，一题只占一个样本；提示辅助的合理学习不扣分。
- **Debugging**：错误发生后，经过后续有效评估确认修复的过程比例；仅运行成功不能证明已经完成题目。
- **Hint Dependency**：首次有效评估前的平台提示使用覆盖率，同时展示提示后通过等指标；高低描述求助方式，不直接评价能力。
- **Transfer**：在已通过来源任务后，进入作者明确标注的新情境任务时的首次评估通过率；重复刷同一题不能增加迁移样本。

每项都显示证据数量；没有合格证据时显示“证据不足”，不会补成 0 分。dry-run、环境故障和未经独立验证的 AI 评审不进入知识/迁移评分，答案查看后的同题结果也不能伪装成新的掌握证据。旧版日志没有评估资格信息的部分会保留，但不会被追溯认定为可靠成绩。

推荐从实际课程中选择，检查难度、前置任务、知识点和已有记录。点击后直接打开指定练习，作为单题练习完成，保留原来的顺序学习进度；做完后刷新诊断查看变化。没有满足条件的候选时会说明原因。

设计参考了本地论文资料中的知识追踪、调试、求助和迁移研究，移除了旧原型的任意加权总分。**这些比例是有文献论证的工程操作定义，并非论文验证过的标准化能力量表，也未宣称训练了 DKT 模型。** 逐篇引用、公式、排除规则和后续效度验证方案见 [学习诊断设计说明](docs/learning-diagnosis-model.md)。

## 执行模式与保存

账号网页启用隔离服务后固定为 `isolated`，由服务端管理执行位置；学习者不能切换为共享宿主执行。未启用服务的兼容账号入口保留 `dry_run`。其他模式用于可信单人或已有教学引擎入口。

- `isolated`：每个账号作业独立 Docker 容器，真实运行课程原始测试；服务或镜像未就绪不会回退到宿主或假装通过。
- `local`：当前 Python 环境的 spark-submit，仅用于可信宿主练习。
- `lakehouse`：Docker 中的 Spark，需要自行准备服务和连接器。
- `databricks`：Spark Connect，需要配置远端环境。部分练习使用本地路径或 JVM 计划接口，不能保证直接适用于 Connect。
- `dry_run`：只检查语法，不计算结果，不记为综合题通过。
- `auto`：运行时检测可用环境。页面修改执行模式后点击“保存设置”才对当前标签页生效；替换 Python/Java 环境需要重新启动服务。

账号的进度、签到与事件保存在 `.sparktutor-web/users/<用户ID>/progress.db`，代码保存在该账号目录下的 `workspace/<course>/<lesson>/exercise_<stepId>.py`，模型配置同样按账号保存。旧单人版本的根目录 `progress.db` 和 `workspace/` 会保留，不会自动归入某个新账号；升级前可在服务器关闭时备份原数据目录，后续迁移时明确选择所属账号。浏览器缓存不会自动覆盖已有服务端文件；并发旧稿会被版本检查拒绝。

重置只清除当前课节进度和受管练习文件，保留其他课节、旧版作业与辅助数据。账号隔离作业超时或取消时会停止并清理对应容器；清理无法确认时不会记录通过，并保留其配额等待管理员处理。旧 `lakehouse` / `databricks` 运行环境的远端资源仍需自行管理。

### 账号隔离执行服务

服务端为已登录用户创建独立容器作业，只提供本次作业文件，并限制 CPU、内存、进程数、时长、并发与输出量。输出、课程测试结果和学习证据绑定原账号、题目、操作标识及作业 ID；失败、超时、取消、服务不可用或其他账号的结果不能放行当前题目。

管理员通过 `--isolated-execution` 或 `SPARKTUTOR_ISOLATED_ENABLED=1` 启用服务；可使用 `SPARKTUTOR_ISOLATED_IMAGE`、`SPARKTUTOR_ISOLATED_DOCKER_EXECUTABLE` 及同前缀的资源配额字段配置镜像和限制。课程原始断言、语法检查不计为真实通过、提示与答案影响规则继续保留。容器为当前部署提供进程、文件与资源隔离，不宣称达到虚拟机级隔离或已完成互联网规模的安全验证。


课程执行测试按实际教材收集全部可执行题目（当前为 27 道），需显式开启 `SPARKTUTOR_TEST_SPARK=1` 并准备 Java 17+ 与 PySpark 4.1.1。未开启时跳过真实 Spark 执行，不能把静态测试通过等同于运行验证。除了参考答案，还应运行错误去重、错误排名、错误聚合和训练数据泄漏等反例，确认它们被对应的课程断言拒绝；环境异常不能作为反例测试通过的依据。课程检查还覆盖题目契约、已有标识兼容、三档难度的必需铺垫及 SQL/水位线等先讲后问的顺序。诊断测试覆盖历史重建、重复/乱序事件、跨课程隔离、缺数据、答案污染、迁移前置条件和推荐导航。

源码位于 `src/sparktutor/`：`courses/` 存课程，`engine/` 管教学、判题与执行，`server/` 提供共享教学协议，`web/` 提供 HTTP、网页会话、代码工作区和离线页面，`state/` 管 SQLite，`config/` 管设置，`app/` 提供可选终端界面（需安装 `.[tui]`）。编辑器源码及锁定依赖位于 `src/sparktutor/web/static/editor-src/`，构建资源和许可证随源码提交。更新内容见 [CHANGELOG.md](CHANGELOG.md)。

安装后，`python -m sparktutor` 和 `sparktutor` 无子命令时默认启动网页服务；显式 `web` 子命令便于传入端口、监听地址和数据目录。可选终端界面使用 `python -m sparktutor launch` 启动，需先安装 `.[tui]`。
