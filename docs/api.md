# 网页版模型接口配置

当前正式入口为网页侧栏“环境与 AI 设置”。完整安装与配置见 [README](../README.md#ai-配置)，教练验收见 [教练说明](coach-acceptance.md)。原 VS Code 扩展的命令面板、设置项及 SecretStorage 操作保留在 [vscode-legacy API 指南](https://github.com/xiangRose/SparkTutor-CN/blob/vscode-legacy/docs/api.md)。

## 哪些功能需要模型

Spark 代码运行、课程原始断言判题、选择题、本地学习画像和合成诊断演示无需模型密钥。导师问答、调试教练和部分没有充分本地规则的开放式短题评审需要模型服务。第一课创建 SparkSession 的短题可本地检查结构，结构通过不表示 Spark 已真实执行。

## 填写并保存

1. 导师提供方可选自动、Anthropic 或 OpenAI 兼容接口。兼容接口按服务商要求填写基础 URL、准确模型名称、密钥与必要的额外请求头；URL 不包含最终的 `/chat/completions` 路由。
2. Anthropic 可单独填写模型与密钥。调试教练固定使用兼容接口配置，不随导师选择回退到 Anthropic。
3. 点击“保存设置”，再分别点击“检查导师连接”和“检查教练连接”。保存本身不请求模型；连接检查发送短测试消息，不发送题面或代码，不计入学习提示。
4. 连接成功后，进入课程做实际问答或教练验收。正文可用不保证模型能稳定满足教练结构，也不代表教学质量已经验证。

默认配置只保留在当前标签页对应的服务内存。勾选“记住本机”可保留非敏感参数；Windows 使用当前服务账户的 DPAPI 加密保存密钥和额外请求头，其他系统没有安全存储时不回退为明文密钥文件。环境变量方式见 README。密钥值不写入浏览器存储、源码或学习备份。

## 执行环境独立配置

选择“自动检测”或“本机 Spark”后同样需要点击“保存设置”。该操作选择执行方式，不能安装 Java/PySpark 或替换服务器 Python。页面出现 `[dry-run] Syntax OK` 时，代码和课程测试均未执行；请按 README 的环境检查和启动方式处理，填写模型密钥不能替代 Spark 环境。

## 连接问题

界面区分认证、限流、超时、空正文、仅思考、截断和格式问题。手动连接检查可以重试旧失败配置；模型不可用时如实显示评审未完成，不据此认定学生答案错误。实际问答和教练请求会将相关题面、当前代码与必要证据发送到选择的服务，详情见 README 的 AI 和数据说明。
