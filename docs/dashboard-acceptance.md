# 第二阶段验收：学习工作台（Issue #6）

本阶段把继续学习、课程进度、四维诊断、知识点证据和推荐练习接入同一页面。评分沿用 Issue #5 的研究依据与操作定义，不新增加权总分；历史复盘与趋势另见 [第三阶段验收说明](history-acceptance.md)。

## 打开开发版

1. 在 VS Code 中打开本项目的 `sparktutor-vscode` 文件夹。
2. 确认 `sparktutor.pythonPath` 指向项目虚拟环境。本机为 `D:\project\AI+KY\sparktutor\.venv\Scripts\python.exe`。
3. 按 F5，在新开的“扩展开发宿主”窗口操作。
4. 按 Ctrl+Shift+P，运行“SparkTutor：打开学习工作台”，或点击 SparkTutor 课程侧栏的主页图标。

基本页面、阅读进度和选择题验收不需要 AI 密钥，也不需要运行 Spark 作业。综合编程题仍需相应 Python、Java 和 Spark 环境。已有数据库可继续使用，不必清空真实学习记录。

## 1. 首页是否清楚、易用

- [ ] 能在一个页面找到继续学习、课程与进度、学习诊断、下一道练习和行为记录入口。
- [ ] 课程与课节使用教材中的标题；两套课程、19 个课节均可见。
- [ ] 窄窗口中按钮和文字仍能使用；切换 VS Code 深色、浅色主题后内容清晰。
- [ ] 无评估记录的维度显示“证据不足”；真实 0% 与缺少证据有区别。

新用户的继续学习区域提供“开始学习”；已有未完成进度时，选择最近更新且仍有效的未完成课节。若所选范围的全部课节完成，页面说明已完成并保留回看入口。删除的旧课节记录不算新课程的完成数；课节无法读取时显示提醒，不能据此宣称全课完成。

## 2. 继续学习能否回到原来的位置

先打开任一课，完成若干阅读或选择题步骤，进入代码题后写一行自己的注释。再打开工作台，点击“继续学习”。

- [ ] 回到已保存的课节、难度和题目位置，而不是自动重头开始。
- [ ] 编辑器中的代码仍在；工作台导航前会保存当前练习并提交待记录编辑。
- [ ] 在另一课推进至少一步或提交一次，再刷新，继续学习目标随有效保存进度更新。
- [ ] 只打开第 11 课，不会把前 10 课误标为已完成。
- [ ] 回看已完成课节并前后翻页，不会丢失已有完成记录；主动重置该课后才清除该完成记录。

课节状态为未开始、学习中、已完成，分别依据每课保存的记录；课节读取异常时显示暂不可用。仅打开题面尚未保存步骤时，不会被当作新的保存进度。已完成表示该课节有完成记录，不证明每个难度都已完成。课节完成率表示已完成课节占目录课节的比例，不能解释为知识掌握度。

## 3. 分数能否解释清楚

提交一道选择题或代码题，然后刷新工作台。展开维度卡片中的“查看计算方式与样本说明”。

- [ ] 能看到计算公式、本次分子和分母、样本单位及具体参与计算的题目或失败过程。
- [ ] Knowledge 按每道题最近一次有效评估统计；同一题多次提交不增加任务样本数。
- [ ] Debugging 的样本是可观察失败过程，包含未修复过程；仅运行成功不会被当作通过题目的修复证据。
- [ ] Hint Dependency 独立描述首次有效评估前的平台提示覆盖；不会被解释为越低能力越强。
- [ ] Transfer 只有具备已通过来源任务、新情境和有效首评时才产生证据；普通练习或重复刷题不会自动成为迁移证据。
- [ ] 知识点详情展示相关任务的最近评估结果，说明同一任务可能关联多个知识点，不能把各知识点计数直接相加。

卡片最多展示每维 100 个计入样本，并注明总样本量；分数仍使用全部合格历史，不受展示上限影响。证据量标记不是统计置信度。平台聊天、外部帮助和没有评估资格信息的旧日志不能据此被完整观测或追溯认定。

仅编辑代码、阅读题面或反复刷新，可以增加行为记录，但不会凭空制造有效评估。查看答案后的受影响评估不作为新的 Knowledge 或 Transfer 证据，相应调试过程按 Issue #5 规则排除。完整研究引用和边界见 [学习诊断设计说明](learning-diagnosis-model.md)。

## 4. 范围筛选与推荐是否一致

在页头将“学习范围”从全部课程改为其中一门。

- [ ] 继续学习、诊断和推荐只面向所选课程；下方仍展示全部课程目录。
- [ ] 诊断可继续使用完整历史检查跨课程的迁移来源，来源证据不会因筛选被删掉。
- [ ] 有合格推荐时，点击“打开推荐练习”可直达那一道题，而不是课节开头。
- [ ] 推荐以单题练习模式打开，不覆盖顺序学习的题目位置；做完后刷新可查看新证据。
- [ ] 无候选时说明原因，不生成虚构练习。刷新或筛选后，旧页面的操作不能打开过期目标。

## 5. 行为记录与读取失败

- [ ] 点击“打开行为记录”，能查看第一阶段的最近学习记录。
- [ ] 没有待记录编辑时，工作台刷新不新增学习事件、不推进课节、不更改代码；之前的编辑如尚未发送，会先补发编辑元数据。
- [ ] 读取失败时能看到明确提示和刷新入口；诊断部分失败时，课程目录与保存进度仍可使用。
- [ ] 原来的“SparkTutor：查看学习诊断”命令仍能使用。
